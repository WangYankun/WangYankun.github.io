# 个人博客 - 使用指南

## 博客概览

这是一个基于 **Hexo + NexT 主题** 的个人博客，部署在 **GitHub Pages** 上。

- **博客框架**: Hexo (Node.js)
- **主题**: NexT v8 (Muse 方案)
- **评论系统**: Giscus (基于 GitHub Discussions)
- **部署平台**: GitHub Pages
- **CI/CD**: GitHub Actions (自动构建部署)

## 快速开始

### 环境要求

- Node.js >= 16
- npm 或 yarn
- Git

### 安装依赖

```bash
cd your-blog-repo
npm install
```

### 本地预览

```bash
# 启动本地服务器
npx hexo server

# 或者
npm run server
```

浏览器访问 `http://localhost:4000` 即可预览。

## 写文章

### 新建文章

```bash
# 基本用法
npx hexo new "文章标题"

# 指定分类
npx hexo new post "文章标题" --category 技术

# 指定标签
npx hexo new post "文章标题" --tags 博客,Hexo
```

文章文件会创建在 `source/_posts/` 目录下。

### 文章模板

每篇文章的开头是 YAML Front Matter：

```yaml
---
title: 文章标题
date: 2026-04-27 14:00:00
tags:
  - 标签1
  - 标签2
categories:
  - 分类1
---

这里是文章内容，支持 Markdown 语法...
```

### 常用字段

| 字段 | 说明 | 示例 |
|------|------|------|
| title | 文章标题 | `我的博客` |
| date | 发布日期 | `2026-04-27 14:00:00` |
| tags | 标签（数组） | `["技术", "博客"]` |
| categories | 分类（数组） | `["笔记"]` |

## 部署

### 自动部署（推荐）

博客已配置 GitHub Actions，只需将代码推送到 `main` 分支，会自动构建并部署到 GitHub Pages。

```bash
git add .
git commit -m "新文章：文章标题"
git push origin main
```

等待几分钟后，访问 `https://username.github.io` 即可看到更新。

## 评论系统配置

本博客使用 Giscus 作为评论系统，需要在 `_config.next.yml` 中配置：

```yaml
giscus:
  enable: true
  repo: WangYankun/blog-comments
  repo_id: R_xxxxxxxx
  category: Announcements
  category_id: DIC_xxxxxxxx
  mapping: pathname
  theme:
    light: light
    dark: dark_dimmed
  lang: zh-CN
```

### 获取 Giscus 配置参数

1. 创建一个公开的 GitHub 仓库（如 `blog-comments`）
2. 安装 [Giscus app](https://github.com/apps/giscus)
3. 在 https://giscus.app/zh-CN 生成配置
4. 将参数填入 `_config.next.yml`

## 个性化配置

### 修改站点信息

编辑 `_config.yml`：

```yaml
title: 你的博客名称
subtitle: '副标题'
description: '博客描述'
author: 你的名字
language: zh-CN
```

### 自定义样式

在 `source/_data/styles.styl` 中添加自定义 CSS。

## 部署到阿里云（迁移指南）

后续如需迁移到阿里云：

1. 购买 ECS/轻量服务器
2. 安装 Nginx
3. 将 `public/` 目录上传到服务器
4. 配置 Nginx 指向 `public/` 目录
5. 绑定域名，配置 HTTPS（Let's Encrypt）
